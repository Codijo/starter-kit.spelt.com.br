# Imagens do README

## `painel.png` — a captura principal

É a primeira coisa que alguém vê ao abrir o repositório, e o argumento do kit é
"dez minutos e você tem um painel no ar". Mostrar o painel vale mais do que
qualquer parágrafo.

**O que capturar:** o Platform logado, em `platform.acme.test`, logo depois do
`dev:token` do passo 9 — a tela que prova que o ambiente subiu inteiro.

**Como:**

1. Janela do navegador em ~1440 px de largura, sem abas nem extensões à mostra.
2. Use o domínio de exemplo do README (`acme.test`), não o nome de um produto
   real — a imagem fica no repositório público.
3. Confira que não aparece token na barra de endereço: o link do `dev:token`
   carrega um, e ele fica no histórico da URL. Navegue para a home antes.
4. Salve como `docs/assets/painel.png`, no máximo ~400 KB.

**Depois:** descomente o bloco `<!-- CAPTURA DE TELA -->` no topo do `README.md`.
